# DonutOrder
Client-side Fabric mod for Minecraft 26.2.
Open the Orders chest GUI, press O: it clicks slot 53 (drop) then slot 54 (next page), 0.5s between each click, until you press O again.
Change slots/delay at the top of src/main/java/com/donutorder/DonutOrderClient.java (slots are 0-indexed there).
